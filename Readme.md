# Proyecto compiladores 2 

Para poder correr el proyecto fase3 en modo de desarrollo para no tener problemas con los CORS se necesita tener instalado python 3.7 o superior para poder correr un servidor http local.
1. Igresar a la carpeta del proyecto fase3
2. En linux abrir una terminal desde la carpeta del proyecto fase3 y ejecutar el siguiente comando:
```bash
python3 -m http.server 8000 #el puerto puede ser cualquiera que no este ocupado
```
3. En windows abrir una terminal desdes la carpeta del proyecto fase3 y ejecutar el siguiente comando:
```bash
python -m http.server 8000 #el puerto puede ser cualquiera que no este ocupado
```
4. Abrir un navegador y escribir la siguiente url:
```bash
http://localhost:8000/
```
5. Listo ya puedes probar el proyecto fase3 en modo de desarrollo.
